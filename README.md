# Boas Práticas ISP - Landing Page Comercial

> Website comercial e institucional para promoção de consultoria especializada voltada a Provedores de Internet (ISPs). Foco em engenharia de redes, governança operacional e evolução técnica de infraestrutura.

---

## 🌐 Visão Geral

O **Boas Práticas ISP** é um website institucional projetado para apresentar serviços de consultoria consultiva para provedores de acesso à internet. A landing page foi estruturada para demonstrar os pilares essenciais de maturidade que um provedor de médio a grande porte precisa para escalar de forma sustentável e segura:

- **Evolução de Engenharia**: Arquitetura de rede (BGP, MPLS, IPv6, CGNAT), redundância física e lógica, e peering em PTTs/IXs.
- **Maturidade de Operação**: SLA/SLO de chamados, documentação de topologia, automação com scripts e monitoramento (SNMP/Zabbix).
- **Governança & Riscos**: Políticas de conformidade LGPD, planos de contingência de backup, segurança perimetral contra incidentes e ataques de negação de serviço (DDoS).

---

## 🛠️ Tecnologias Usadas

* **Estrutura**: HTML5 semântico e SEO-friendly.
* **Estilização**: Vanilla CSS customizado (design responsivo com gradientes suaves em tons verdes, simbolizando estabilidade e crescimento).
* **Ícones**: SVG inline para melhor performance e zero dependências externas.
* **Hospedagem**: Desenvolvido para publicação em GitHub Pages ou Vercel.

---

## 🚀 Como Executar Localmente

Não há dependências adicionais ou scripts de build.

1. Abra o arquivo `index.html` diretamente em seu navegador web.
2. Ou inicie um servidor web simples:
   ```bash
   python -m http.server 8000
   ```
   E acesse no navegador: `http://localhost:8000`.
